# 完整 Krita：第一次真机验收

本表针对 `.build/krita-ios-install/krita.app`，与已通过的 KritaIOSProbe 分开记录。
当前均为待验证；编译成功不能替代这些步骤。

1. 使用自己的签名方式签名应用，安装到 iPad Pro M5。默认标识为 `org.example.krita`，不覆盖探针。
2. 横屏打开 Krita，记录是否进入原版主窗口、是否提示资源数据库或默认笔刷缺失。首次初始化可能比后续启动慢。
3. 新建 1024 × 1024、8 位 RGBA 文档。确认画布显示，选择默认 Pixel 笔刷。
4. 用 Pencil 连续画线，检查笔尖与笔迹是否重合。改变压力和倾角，分别记录结果；笔迹粗细变化不单独作为倾斜证据。
5. 用手指操作画布，检查是否出现误画；测试缩放后笔尖与笔迹是否仍重合。
6. 添加图层，绘画后撤销/重做，确认图层与画面同步。
7. 保存 .kra，关闭文档，再打开确认图层和笔迹。当前 Files 导入导出尚未完成整合，记录实际对话框行为。
8. 退出并重新打开应用，检查资源数据库、设置及文档恢复。

如启动即退出，保留 Xcode Devices and Simulators 中对应的设备崩溃日志，尤其是异常类型、终止原因和调用栈。不要将探针截图作为完整 Krita 启动证据。

已知范围：完整应用尚未接入默认 150% 可配置 GUI 缩放；Files 资源导入、自动保存恢复、外接键盘/鼠标、Pencil 倾斜和 OpenGL ES 实机行为仍待验证。
